# 협력사 과제 관리 대시보드

> 공개 저장소에는 원본 엑셀·DB(`data/`)·`.env` 가 포함되어 있지 않습니다. 협력사명은 익명(협력사A·협력사B)으로 바꿨으며, 원본 엑셀이 있어야 가져오기·테스트가 동작합니다. 설정은 `.env.example` 을 `.env` 로 복사해 사용하세요.

## 실행
1. `start.bat` 을 더블클릭합니다. 서버가 준비되면 브라우저가 자동으로 열립니다 (내부에서 `start.ps1 -OpenBrowser` 실행. 오류가 나면 창이 닫히지 않고 멈춰서 메시지를 보여 줍니다).
   - 처음 실행이면 원본 엑셀 4개에서 데이터를 가져옵니다(협력사A 18건, 협력사B 83건).
   - 이전에 띄운 서버가 남아 있으면 먼저 정리합니다.
2. 브라우저에서 http://127.0.0.1:8765/ 을 엽니다.
3. 끌 때는 `stop.bat` 더블클릭(또는 서버 창에서 Ctrl+C). 서버 창을 X 로 닫아 서버가 남아 있어도 `stop.bat` 이나 다음 `start.bat` 이 정리합니다.

처음 설치(가상환경이 없을 때):
```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## 사용
- **협력사**: 왼쪽 「협력사 추가」, 이름 옆 연필 아이콘으로 수정·삭제. 삭제는 함께 지워질 과제·이력·메모 건수를 확인한 뒤에만 실행됩니다.
- **카드**: 클릭하면 아래 목록이 그 조건으로 걸러집니다(진행중·완료·지연·이슈·예정일 미입력).
- **과제**: 과제명을 누르면 팝업. 저장 버튼 하나로 기본정보·성과·추가 정보·진행 이력을 함께 저장합니다.
  - 진척률은 「진행 이력」 탭에서만 입력합니다. 같은 주차 기록이 있으면 그 기록을 고칩니다.
  - 상태를 「완료」로 바꾸면 진척률 100% 기록과 실제 완료일(오늘)이 채워집니다.
  - 개선전·개선후가 숫자면 개선효과·개선율이 자동 계산되고, 아니면 개선효과를 직접 입력합니다.
- **진행사항 엑셀**: 목록 위 「진행사항 양식」으로 주차를 골라 과제 목록 엑셀을 받고, 노란 칸(진척률·진행 내용·이슈)을 채워 「진행사항 업로드」로 올립니다. 미리보기에서 새 기록·수정·오류를 확인한 뒤 「반영」을 눌러야 저장되며, 오류가 1건이라도 있으면 반영되지 않습니다. 이 프로그램이 만든 양식만 받습니다(다른 협력사 양식·원본 엑셀은 거부). B2 칸의 주차를 바꾸면 다른 주차로 올릴 수 있습니다.
- **주간 보고 입력**: 주차별 컨설팅 요약·공통 사항·차주 방문·차주 계획. 과제별 금주 내용은 그 주차의 진행 이력에서 자동으로 들어갑니다.
- **보고서 다운로드**: 고른 주차까지 누적된 Feedback Report 엑셀. 원본 파일의 과거 주차 시트는 그대로 두고, 그다음 주차부터 시스템이 시트를 만듭니다. 빈 칸이 생기는 이유(메모 없음 등)는 다운로드 전에 표시됩니다.

## 백업과 복원
- 앱을 켤 때마다 `data/backup/app_YYYYMMDD-HHMMSS.db` (KST) 로 자동 백업하고, 최근 30개만 남깁니다. 실행 창에 `integrity=ok` 가 찍히면 정상입니다. 상단 「백업」 버튼으로도 만들 수 있습니다.
- **복원 순서**
  1. `stop.ps1` 로 서버를 끕니다.
  2. `data` 폴더에서 `app.db`, `app.db-wal`, `app.db-shm` 세 파일을 다른 곳으로 옮깁니다(`-wal` 이 남아 있으면 백업 이후 기록이 다시 얹힙니다).
  3. 되돌릴 백업 파일을 `data\app.db` 이름으로 복사합니다.
  4. `start.ps1` 로 다시 켭니다.

## 원본 데이터 다시 가져오기
`.venv\Scripts\python -m app.importer --force` — 현재 데이터를 백업한 뒤 모두 지우고 원본 엑셀에서 다시 가져옵니다.
